# Personal Life OS · Cloud Edition

Public program only. Never commit personal settings, backups, health records, tokens or private data here. Upload files in this folder to a public repository root; enable Pages from main / root. HTTPS is required for PWA install.

Personal data stays in browser storage or a dedicated private GitHub repository. Only grant a fine-grained token for that private repository, Contents read/write. Token is held in RAM; reauthorize after app reload. Offline edits are saved locally and sync while connected. Conflict prompts are intentional. Never publish the private repository or turn on Pages there. Git history may retain old records. Browser storage is not encrypted; same-origin pages can access it. Use a trusted dedicated origin or separate browser profile where practical. No remote images or third-party JavaScript.

Existing V4 backups are importable; import replaces local state. Back up first. New fields can be entered in Settings > 私人配置.
